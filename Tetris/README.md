# Tetris learning project

Unity coursework with grid, piece data, tetromino, game-state and UI components.

Start with [GridManager.cs](Assets/Scripts/GridManager.cs), [Tetromino.cs](Assets/Scripts/Tetromino.cs) and [PieceData.cs](Assets/Scripts/PieceData.cs).

Use [the recorded editor version](ProjectSettings/ProjectVersion.txt). This is a learning prototype, not a finished release; no fresh import/runtime pass is claimed.
