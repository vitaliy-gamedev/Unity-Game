# Drone controller study

Educational Unity prototype with scout/bomber drone controllers, targets, scene managers, localization and HUD components.

Start with [ScoutDroneController.cs](Assets/Scripts/Drones/ScoutDroneController.cs), [BomberDroneController.cs](Assets/Scripts/Drones/BomberDroneController.cs) and [TargetEntity.cs](Assets/Scripts/Targets/TargetEntity.cs).

Use [the recorded editor version](ProjectSettings/ProjectVersion.txt). This folder is historical coursework, not a released simulation product.
