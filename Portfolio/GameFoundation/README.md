# GameFoundation

**Personal reusable Unity toolkit | Published on itch.io and Fab**

[Portfolio and demonstrations](https://gamefoundation-pro.nortczov.chatgpt.site/) · [itch.io products](https://vitaliy-gamedev.itch.io/) · [Fab listing](https://www.fab.com/listings/6ef15521-7164-4406-ab89-f71cd00cb4d4)

## Scope

- Menu and UI navigation systems.
- Settings, audio and localization (EN / UA / FR).
- UI themes and scene/loading flows.
- Starter, Pro, Windows Expansion and Mobile Expansion variants.

## My contribution

Requirements and priorities, Unity scene/UI assembly, integration, configuration, clean-project import checks, issue reproduction, package preparation, documentation and demonstrations.

This is a published personal product, not employment at a game studio. The development workflow is described in the [portfolio overview](../../README.md#my-contribution).
