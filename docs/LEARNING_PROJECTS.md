## Opening historical projects

1. Choose one project folder, not the repository root.
2. Check `ProjectSettings/ProjectVersion.txt` and use that editor version in Unity Hub.
3. Let Unity restore packages from that project's manifest.
4. Inspect its scenes/scripts; external resources may be required.

These exercises have not all been re-imported or re-tested. The current playable showcase is [RED ZONE](../Portfolio/RED_ZONE/README.md); the source-only showcase is [DEADBAND](../Portfolio/DEADBAND/README.md).

Generated compiler output and caches are excluded from the current tree. Third-party assets retain their original terms; these README files grant no new reuse license.
